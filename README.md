# Kartarpur-0 (commune-os)

An open-source blueprint and civic operating system for an automated, post-scarcity commune grounded in universal Sikh ethics (*Kirat*, *Vand Chhako*, *Seva*, *Langar*, *Miri-Piri*).

## Hierarchy
* **Tier 1: Kartarpur-0** — Local micro-village node (~150 residents).
* **Tier 2: Anandgarh** — Regional fabrication, acute care, and compute hub (~1,500 residents).
* **Tier 3: Sanjha Raj** — Bioregional federation managing watersheds, transit, and grid balancing.
* **Tier 4: Gyan Sagar** — Global open-source design commons, digital twins, and simulation models.
